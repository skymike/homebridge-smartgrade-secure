# Security

Do not post credentials, session files, phone numbers, OTP codes, or unredacted account and device identifiers in public issues.

Report vulnerabilities through this repository's GitHub **Security → Report a vulnerability** feature. If private reporting is unavailable, open an issue asking for a private contact without including sensitive details.

The current published version receives fixes. Update to the latest release before reporting a problem. This unofficial integration depends on a third-party cloud API; cloud status is not an independent physical safety measurement.
